## 1. 核心目标与范围

面向 AI 高模重拓扑后的低模，在固定 **1024² 纹理预算**下，联合优化近似区域对应、共享 UV、接缝及排布，提高模型表面的有效纹素密度，同时控制畸变、密度分配、外观误差和采样安全。允许左右几何、顶点数量和三角形划分不同；严格镜像配对仅作基线。相似区域部分共享，不适合共享的细节保持独立。`[opinion]`

固定使用幻想龙 `dragon`（2000 面）和能量刀 `energy_blade`（500 面），以 [资产 manifest](../assets/v1/manifest.json) 校验输入；保留原始几何、面集合和稳定身份。Artist GT 仅为独立参考，不替换固定低模或强制其对称化。`[verified: 用户已确认的固定资产和近似对称方向]`

完整流程：

**近似曲面对应 → 连续区域与成对参数化 → 部分共享 → 安全排布 → 根据排布/畸变瓶颈重构接缝 → 整体验收与回退 → 重烘焙和评审。** `[opinion]`

OT、AT、SQP 是可选实现路线，不作为必须复现的论文方法；Texture Carving、上游生成和重拓扑算法研发不列为本版必交付项。V1 原始目标和验收口径保持历史定义。`[opinion]`

## 2. Subagent 代理盲评

人工评分不再阻塞自动实验。新增 **subagent 代理盲评**，代理结果明确标为 `AGENT_EVALUATED`；保留人工后续复核入口，不能将代理结果写成真实 artist 已验收，也不能伪造人工确认区域或编辑时间。`[verified: 用户要求“人工可能不能及时打分，可以用 subagent 评分”]`

- 每个模型／种子的匿名比较包由 **3 个全新上下文的评审 subagent**分别评价；不共享彼此评分，不提供方法名称、历史排名、源码路径或预期结论。同模型的多个评审不视为统计独立的真人专家。
- 所有方法使用相同参考图、相机、光照、展示比例和局部裁剪；包内包含 UV、真实贴图模型、接缝局部、法线和 mip 对拍。匿名编号预先固定，不随成功样本集合变化。
- 分别给出 **外观保真、接缝/串色、法线/mip、UV 可编辑性代理**四项 1–5 分；另给成对偏好“胜／平／负／无法判断”。每项评分引用具体图片、视角或区域，不从几何指标猜测视觉结果。
- 各维度取中位数，保留原始评分、分歧和理由。至少两份有效评审才形成汇总；缺失证据不猜分，失败最多重试一次，不足则标 `UNSCORED`。
- 技术门禁优先，代理评分不能放宽几何、畸变或 padding 约束。开发评审可以指导修改；正式测试盲评只在配置冻结后开展，不将其反馈用于同轮调参。`[opinion]`

## 3. A/B 与消融协议

四组对照固定为：

1. **固定岛排布基线**：不复用、不重构接缝。
2. **仅接缝—排布优化**：不允许复用。
3. **仅近似复用**：完成对应、成对 UV 和复用组排布，不启用 packing 反馈的接缝搜索；隔离复用区域所必需的边界切缝计入该方法成本。
4. **完整联合方法**：同时启用复用与接缝—排布反馈。`[opinion]`

两模型 × 四组 × 种子 **17、29、43**，最低 **24 个预定运行**。同模型同种子使用一致的初始条件、质量要求、搜索预算和下游配置；独立启动，不继承上一轮最好结果。初始化、失败候选、验证及回退成本计入耗时。`[opinion]`

重点比较完整方法相对“不复用”“无接缝反馈”和固定岛基线的变化。几何指标、有效输出率、耗时、代理偏好分别报告；保留中位数、范围和逐种子结果，不只展示最好一次。两模型仍是开发／回归集，不宣称独立模型泛化。`[opinion]`

## 4. 结论记录与验收

每轮必须记录：

- **运行前**：研究问题、假设、比较组、接受规则、预算、输入/代码/后端版本、评审提示词和固定匿名映射。
- **运行中**：对应区域、复用组、删缝/加缝、求解与排布结果、接受/拒绝原因、回退和耗时。
- **运行后**：完整矩阵、客观指标、代理原始评分与汇总、负结果、限制及下一步决定。`[opinion]`

结论明确区分 **已实现、已验证、代理偏好、待验证假设**；性能主张链接到对应运行和产物。诊断、部分结果不能写成完整 A/B；评审分歧、失败与未运行项不得剔除。`[opinion]`

验收分三层：

- **技术完成**：对应、共享、联合搜索、验证和回退流程可运行，必要测试通过。
- **实验完成**：预定矩阵与盲评全部完成；若预算耗尽，只交付带明确缺口的报告，不标完整实验完成。形成可复现结论，不要求必须胜过基线。
- **交付评价**：分别报告技术门禁与代理推荐状态；人工复核状态独立记录，人工缺席不阻塞前两层。`[opinion]`

唯一覆盖率、复用比例、表面纹素密度和外观误差分别统计；不能将重复 UV 面积相加冒充唯一利用率，不能用整图低误差掩盖共享区域局部失真。曲面对应记录包含目标面和重心坐标，接受对应不等于批准任意组内交叠。`[opinion]`

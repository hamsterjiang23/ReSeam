## 核心目标

V1 自动 A/B 的历史目标与结果冻结；用户已批准开展 [V2 固定岛排布对照](v2.md)。空间利用率属于 V2 的新目标，不追溯更改本页验收口径，V1 artist 人工验收继续待完成。`[verified: 本轮用户选择固定 UV 岛 Packing 对照]`

面向 Tripo 等 AI 生成高模经过重拓扑后的低模，生成便于艺术家编辑、支持可靠 Blender 烘焙及后续可微贴图优化的 UV，减少人工修整成本。

在固定低模上联合搜索接缝与 UV 坐标，在映射合法、拉伸畸变受控的前提下，改善接缝位置、重要区域连续性和碎片结构。通过 A/B 测试判断可撤销区域级重构与自适应松弛是否带来同预算收益，再分别检验 artist 可用性与下游贴图质量。

V1 完成意味着交付可运行原型、可复现实验和有证据的结论，不以必须获得正向收益为完成条件。

## 生产场景与 artist 目标

目标流程：单视角输入与多视角图生成 → AI 高模生成 → 不同算法重拓扑 → **ReSeam UV 展开** → Blender 贴图烘焙 → 可微贴图优化。V1 只研发 UV 环节，复用上下游工具作为数据来源与验收依赖。

artist 可用性按以下要求设计与评价，不预设岛越少越好：

- **接缝合适**：保护脸部、标志和主要纹样等指定连续区域，支持必须切、禁止切及偏好切约束。
- **区域可编辑**：减少无意义小岛、细长分支与曲折边界，保持部件可识别；允许为编辑便利保留合理的多岛结构。
- **质量可交付**：控制局部拉伸，减少烘焙后的可见接缝、串色与纹样破坏；分别检查 Base Color 和切线空间法线。
- **人工成本可衡量**：预先定义编辑任务、交付标准与时间上限，匿名盲评并记录修整用时、修改操作及限时未完成情况；几何指标不替代人工评价。

## 范围

- 保持原始几何与面集合不变，只沿原始网格边修改接缝。
- 初始 split 仅作初始化，允许跨分区删除旧接缝、添加新接缝，并整体评价复合修改。
- 根据候选求解情况扩大 UV 顶点活动范围；保持畸变与合法性约束不变。
- 优先从 OptCuts 展开结果出发，进行语义区域保护下的碎片修复与接缝重构；保留原版作为强基线，后端可替换。
- 可使用高模材质、部件及高低模对应信息指导候选，须记录可信度；不可靠或缺失时回退到几何或人工标注，不以 AI 纹理瑕疵定义真实边界。
- 保存 packing 前 UV。V1 不优化贴图空间利用率，不实现 V2 排布与装箱。

纯几何目标函数、畸变定义和合法性要求沿用 [README](../README.md) 与 [研究报告](UV_展开方案_研究报告_v0.1.md)。机制验证使用 λ_K = 0；低碎片实验使用预先固定的 λ_K > 0。artist 约束、软偏好和候选接受规则单独锁定并消融，不将原几何目标当成 artist 质量的完整定义。

## 固定模型与多轮测试

模型固定为之前会话使用的能量刀 `energy_blade`（500 面、252 顶点）和幻想龙 `dragon`（2000 面、996 顶点）。[assets/v1](../assets/v1/README.md) 已包含两套真实材质参考高模与无 UV 低模，入口及哈希以 [manifest.json](../assets/v1/manifest.json) 为准。

默认直接使用历史低模进行各方法对照；其他重拓扑方法和面数档位仅从这两套高模派生，另建 variant。固定输入不得因某个方法表现差而修改或替换。

[Artist 真值参考](../assets/gt/README.md) 已另行提供，保留其 UV 通道、曲面分量和复用情况作独立参考。它们与固定低模的面数和拓扑不同，不计入同拓扑 A/B，也不自动产生固定低模的硬接缝约束。

多轮方法测试保留 OptCuts、xatlas、Blender Smart UV、PartUV 及 ReSeam 消融。每次算法或配置修改创建独立 round_id；同轮固定输入、质量标准和预算，随机配置默认种子 17、29、43，至少三次独立重复。确定性重复只用于耗时与一致性检查，不能增加独立样本量。

严格执行 [资产目录的多轮协议](../assets/v1/README.md)：先冒烟，再锁定正式配置；逐次保存版本、哈希、初始化和失败记录，不覆盖历史输出，不挑最好一次当作完整结果。这两个模型为开发与回归集，未见视角评价不能替代独立模型泛化检验。

## A/B 对照

1. **接缝重构**：固定初始分区边界，对比允许跨分区区域级复合重构；共享初始状态、后端、松弛策略、质量要求和总预算。
2. **松弛范围**：固定候选池与共同 UV 起点，对比小范围、大范围和自适应范围；加入等预算对照，区分范围扩大和额外计算的收益。
3. **完整方法**：与原版 OptCuts、同预算多起点 OptCuts、固定分区组合基线比较，检验收益是否仅来自初始化或更多尝试。
4. **artist 约束**：固定搜索机制比较有无 artist 约束，再固定 artist 约束比较搜索机制，分别报告约束遵守、可编辑性和人工修整成本。
5. **重拓扑稳定性**：同一高模的不同重拓扑方法与面数档位分别固定低模测试，跨组分析收益与失败范围；不把上游几何质量差异归因于 UV。

几何指标包括完整有效输出率、首次可行解耗时、归一化接缝长度、岛数量、目标值、平均与尾部及最大畸变，以及最佳可行质量随时间的变化。应用指标包括约束违背、部件连续性、小岛面积占比、狭窄区域与边界曲折、盲评偏好及人工修整用时；具体定义在正式实验前锁定。

诊断记录包括支持域救回率及分母、接缝删除与新增量、活动范围、接受率和失败原因。端到端计时包含初始化、失败候选、求解及验证；统一外部 packing 和下游验收耗时单独记录。

烘焙对照固定排布器、贴图分辨率、纹素密度规则、像素间距与 cage，检查接缝附近颜色误差、纹样连续性、多个 mip 层级及切线空间法线。可微优化固定预算，校准渲染、采样和颜色空间，训练、调参与最终评估视角分离；分别报告 Blender 初始化和优化后质量，不预设后者更好。

记录高低模对应可信度、投射失败与几何差异；UV 优化不承担修复错误几何或跨表面投射的职责。

## V2 进入条件

完成 V1 A/B 并形成可追溯结论后，再设计 V2 排布与装箱目标、空间利用率指标及约束。V1 结果用于决定是否保留或调整现有机制，不预先承诺联合优化切法与装箱。

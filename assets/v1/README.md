# V1 固定测试资产

本目录固定使用会话 `01a0ae39-4fe3-7b12-9430-d75932487914` 中的两套模型，作为多轮方法开发与回归测试样本。资产已复制并校验，原项目文件保留；当前尚未在 ReSeam 仓库运行 UV 或烘焙实验。

## 模型清单

- **energy_blade／能量刀**：历史低模版本 `QEM4VR_500faces`，低模 500 个三角形、252 个顶点；本次迁入的历史参考高模为 1630 个三角形。
- **dragon／幻想龙**：历史低模版本 `Dragon_RobustLPM_2000faces`，低模 2000 个三角形、996 个顶点；本次迁入的历史参考高模为 22730 个三角形。

上述高模指旧实验实际使用的参考文件，不宣称是生成服务未经处理的原始输出。模型来源于用户指定的 AI 资产流程；具体生成器版本与原始生成参数尚无完整元数据。

每个模型目录包含：

- `high.glb`：后续真实材质烘焙实验使用的参考高模，材质和图像内嵌，可独立读取。
- `low.glb`：旧 UV 对比实验使用的固定低模，已恢复拓扑并对齐高模，无已有 UV。
- `low.obj`：该低模的 OBJ 版本，供不同后端读取。

能量刀使用真实材质高模，不使用旧 UV 诊断实验中替换过棋盘格的 `high.glb`。已对齐的低模不得再次套用历史 alignment 变换。

## 来源与完整性

[manifest.json](manifest.json) 是当前资产入口，记录相对路径、源路径、SHA-256、大小、模型信息与迁移检查范围。运行时使用仓库内相对路径；源路径仅用于追溯。

[能量刀来源记录](provenance/energy_blade_source_manifest.json) 与 [幻想龙来源记录](provenance/dragon_source_manifest.json) 是原样保留的历史记录，其中的旧路径、旧高模哈希及 `texture_kind` 不能覆盖当前 manifest 的输入选择。

已检查复制前后 SHA-256 一致、GLB 头和分块、bufferView 范围、内嵌资源、面数和顶点数、低模 UV 缺失，以及 OBJ 三角面与索引范围。尚未运行完整 glTF 验证、流形与相交检查、GLB/OBJ 逐顶点等价检查或实际烘焙；不得将资产迁入当成算法测试通过。

## 多轮测试规则

1. 默认模型清单始终为 `energy_blade` 和 `dragon`，每轮两者都进入矩阵；禁止因失败或结果不好静默替换或剔除。小规模冒烟只先跑能量刀，再扩展幻想龙。
2. 原始资产保持只读使用，不覆盖。新增重拓扑方法与面数档位仅从这两个高模派生到独立 variant，并记录父资产哈希、工具版本和参数；不能替代固定历史低模基线。
3. 对照方法包括原版 OptCuts、xatlas、Blender Smart UV、PartUV，以及 ReSeam 的重构／松弛／artist 约束消融；未接通或运行失败的方法如实标记，不伪造结果。
4. 每次改变算法、参数或质量协议建立新的 `round_id`。同轮固定低模、质量阈值、时间预算和下游设置，按模型配对比较；跨轮修改必须有配置差异记录。
5. 正式随机方法每个配置至少使用种子 `17、29、43` 三次重复。确定性方法可重复三次测耗时与一致性，标为 deterministic；重复或多种子不增加独立模型数量。
6. 各重复从相同指定初始化独立开始；ReSeam 从 OptCuts 初始化时明确记录并计入其计算成本，不继承上一轮最好结果冒充独立试验。多起点对照使用相同总预算。
7. 每次运行先核验输入哈希，保存方法和后端版本、种子、初始化、阈值、预算、硬件、状态和耗时。质量阈值及预算尚待开发集测量后锁定；缺少配置时不得启动正式 A/B。
8. 输出到 `artifacts/v1/<round_id>/<model_id>/<variant_id>/<method_id>/seed_<seed>/`，每个运行目录不得覆盖。保存配置、日志、接缝、原生 UV、统一打包 UV、真实贴图低模与指标；失败和超时也保存结果记录。
9. 报告按模型与配置汇总重复结果及失败率，不只挑最好一次。输入哈希、目标或评价器版本不同的结果必须分组，不直接合并排名。

这两个模型已用于观察和迭代，属于固定开发与回归集，不能声称是未见测试集。独立相机视角验证不等于独立模型泛化；本阶段结论限定为这两套资产及其明确派生版本。

V1 的完整目标和人工验收要求见 [goal/v1.md](../../goal/v1.md)。

# 整龙 LLM UV 复用：执行合同

本轮以 tripo_p2 规范化模型为固定父资产；允许左右细小颜色差异对称化，保护头脸特征；交付范围为 UV 与 BaseColor，完整 PBR、GPU、人工状态单列。原始输入和旧实验保持不变。`[verified: 用户接受的整龙计划]`

## 对照

四条路径独立初始化：原UV必要修复无共享、OptCuts区域展开无共享、纯几何复用、Agent迭代复用。公共预处理、候选池、起点、后端、质量和执行预算相同。另单列不同提案来源的端到端比较；冻结最终对称化目标后，使用同目标无共享对照区分外观修改与共享收益。`[opinion]`

候选尺寸512/1024/2048/4096/8192；颜色验收LOD0/1/2，完整mip交付另计；枚举不假设成功单调。每次工具默认300秒，失败、超时、未运行均留在矩阵。代码修正影响某条路径时另建轮次，不拿旧代码Baseline比较新结果。`[opinion]`

## 关键步骤证据

导入规范化、区域定义、对应、重构接缝、展开、共享、对称化、排布、缩图每步保存：父/子快照哈希、同视角图、指标及变化量、Agent理由与输入、耗时、接受或拒绝及失败面。消融必须从同一父状态只改变研究变量；源码修复另存最小失败反例和回归测试。`[opinion]`

## 工具与判断

region.define记录语义面集合；uv.reparameterize允许显式OptCuts或内部共同域准备；reuse.check_pair先拓扑对应再共同域；material.target冻结源信号；basecolor_reuse执行独立范围验收。所有变更仍须逐面仿射、单射、方向、畸变及授权交叠检查。`[opinion]`

OptCuts在本轮作为用户明确授权的实验后端，不改变历史自研求解器/原始数学问题的范围。源码参考保持只读，运行适配位于项目工具层。`[verified: 用户明确允许OptCuts等几何工具]`

# Artist 质量参考与反馈

用户已确认：冒烟样例 ReSeam 为 3 分、OptCuts 为 4 分，均未达到交付标准；扣分原因是“Reseam的UV岛屿之间的黑色区域太多了”。这是初步视觉偏好，不是限时修整或正式 A/B 验收。

对应相同排布设置下的 UV 三角形覆盖率为 ReSeam 47.82%、OptCuts 48.77%。覆盖率不含扩边，空白还包括必须保留的岛间距、外边距及形状排布空隙；不能仅依据彩色像素比例计算。

用户另外提供了游戏资产成品贴图作为视觉目标。该 PNG 为 256×256，SHA-256 为 `0230cebaa47099f9b7be8276bc8d3f7195397d04c3d571ee86a2aa24682a0340`，存于本地 `artifacts/feedback/game_atlas_reference_20260918/texture_reference.png`。图片没有对应网格和 UV 轮廓，不能据此量化其真实 UV 利用率或判断是否存在叠 UV。

交付对比需并列展示 UV 岛轮廓、烘焙颜色贴图、同视角模型与接缝局部，并报告统一排布后的覆盖率。几何目标改善而排布更松散时，记录该代价，不能据岛少或接缝短宣称 artist 质量提升。

当前冻结 V1 实验继续研究展开与切缝；覆盖率作为下游诊断。V2 再研发排布与装箱。以上反馈不构成必须切／禁止切边的人工标注，也不改变已经锁定的实验目标或阈值。

原始评分与原话记录在本地 `artifacts/feedback/initial_visual_preference_20260918/`；不将这些冒烟反馈混入新轮匿名样例评分。

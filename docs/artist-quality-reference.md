# Artist 质量参考与反馈

用户已确认：冒烟样例 ReSeam 为 3 分、OptCuts 为 4 分，均未达到交付标准；扣分原因是“Reseam的UV岛屿之间的黑色区域太多了”。这是初步视觉偏好，不是限时修整或正式 A/B 验收。

对应相同排布设置下的 UV 三角形覆盖率为 ReSeam 47.82%、OptCuts 48.77%。覆盖率不含扩边，空白还包括必须保留的岛间距、外边距及形状排布空隙；不能仅依据彩色像素比例计算。

用户另外提供了游戏资产成品贴图作为视觉目标。能量刀 PNG 为 256×256，SHA-256 为 `0230cebaa47099f9b7be8276bc8d3f7195397d04c3d571ee86a2aa24682a0340`，原始副本在本地反馈目录，仓库副本为 `assets/gt/energy_blade.reference.png`。图片本身不含网格和 UV 轮廓，不能单靠彩色像素量化利用率。

第二张龙纹样贴图由用户明确说明为“另一个真实的 artist 的真值”，SHA-256 为 `8621c3dd1c2a5d28502e0d598170f7b34fa9501156ef5c24c60fbc09d1f7fbb0`，仓库副本为 `assets/gt/dragon.reference.png`。

用户随后提供了 [两份带 UV 的 FBX](../assets/gt/README.md)。只读检查已输出逐对象／逐通道指标和贴图叠加视图：能量刀 UVChannel_1 的并集覆盖为 69.08%，龙主体为 46.18%；两者均有重复覆盖。统计按原始 FBX UVIndex 连接，不按坐标接近焊接。

GT 能量刀为 218 三角面；GT 龙主体为 2754 三角面、31 个按边相连的曲面分量，另外有两个辅助平面对象。它们与固定 500／2000 面低模的拓扑不同，不能混入同网格性能排名。图集覆盖、重复利用、部件连续性和密度分布须分开看；图中颜色铺满也不等于整个图集都被当前主体使用。原始着色器绑定不完整，关联展示不证明游戏引擎中的实际通道与采样设置已复现。

质量目标明确为：**在不牺牲 UV 拉伸、合理的 Texel Density 和安全 Padding 的前提下，提高 UV 岛的有效面积占用率；岛间距只需满足安全要求，不是越小越好。** 烘焙 Margin／Dilation 与岛边界之间的距离分别记录，不混用两个像素值。

交付对比需并列展示 UV 岛轮廓、烘焙颜色贴图、同视角模型与接缝局部，并报告统一排布后的覆盖率。几何目标改善而排布更松散时，记录该代价，不能据岛少或接缝短宣称 artist 质量提升。当前配置保持 1024²、至少 16 像素岛间距及 8 像素烘焙扩边；不根据示例经验表在实验中途缩减。

当前冻结 V1 实验继续研究展开与切缝；覆盖率作为下游诊断。V2 再研发排布与装箱。以上反馈不构成必须切／禁止切边的人工标注，也不改变已经锁定的实验目标或阈值。

原始评分与原话记录在本地 `artifacts/feedback/initial_visual_preference_20260918/`；不将这些冒烟反馈混入新轮匿名样例评分。

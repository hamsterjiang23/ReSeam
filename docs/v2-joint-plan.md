# V2 联合实施计划

本计划对应已归档的V2实现。后续方案按 [求解器重新设计](../goal/solver-redesign.md) 开展，不直接延续本计划的OptCuts后端或初始化依赖。`[verified: 用户本轮方向更新]`

状态：联合原型、v2_joint_round01的24项搜索/下游和18份有效代理盲评已完成；真实复用未成功，详见 [实际结论](v2-joint-results.md)。运行入口见 [V2运行说明](running-v2.md)。上位目标为 [goal/v2.md](../goal/v2.md)；[固定岛计划](v2-plan.md)、[整面复用诊断](v2-reuse-plan.md) 和已有报告保留为历史阶段，不适用本轮新预算和代理验收规则。`[verified: 用户确认的 V2 目标修订方案]`

构建：近似区域复用与接缝—排布反馈的可运行联合原型。
方案：Python 外层事务搜索，独立成对 UV 求解器，统一复用组排布、重烘焙和匿名评审。
首要风险：顶点—曲面对应不保证连续或双射，不能直接把最近点关系作为合法共享 UV。`[opinion]`

## 1. 数据、接口与接受规则

### 状态和输出

- 保留 V1 的 MeshState、稳定原始面/边身份；新增 V2State，包含表面 UV 副本、接缝、区域对应、ReuseGroup、组级排布变换、版本和最好合法档案。一个 ReuseGroup 最多包含两侧区域；一张原始面只属于一个组，未共享区域视为单成员组。
- Correspondence 记录源面/角或采样点、目标面及重心坐标、镜像平面、位置/法线/往返误差和有效掩码。RegionPair 记录两侧原始面集合、边界、方向奇偶性及有效覆盖，不能以几何接近合并原始顶点身份。
- V2Candidate 是完整事务：区域删/加缝、复用组增删、共同初始化、求解支持域及排布提案一起评估。求解器返回 SOLVED、INIT_FAILED、CORRESPONDENCE_INVALID、NUMERICAL_FAILURE、QUALITY_REJECTED、TIMEOUT_WITH_BEST 等明确状态。
- UV 重叠许可采用“组成员＋实际曲面对应”检查，不扩展为同组任意三角形可以重叠。保留原始表面 UV 与只用于 packing/bake 的代表域之间的映射，不删除导出模型上的任何面。`[opinion]`

已新增命令为 `reseam joint-unwrap`、`joint-benchmark`、`review-export`、`review-import`、`joint-report`；接口实现见 src/reseam/cli.py；完整验收仍以正式矩阵为准。参数沿用 model、seed、config、output、seconds，并增加 track。每次输出独立目录，包含 state、correspondences、reuse_groups、candidate 日志、objective、quality、source、budget 及渲染产物；存在目录即拒绝覆盖。V1 命令和验证器不改变语义。`[opinion]`

### 优化目标与首轮数值默认值

以下是**拟实施的首轮配置**，不是已证实的普适 artist 阈值。构造测试与开发冒烟可以暴露配置不可行；修改后使用新开发轮，正式矩阵启动前锁定最后版本，禁止按正式结果反调门限。`[opinion]`

- 主指标为面积加权密度增益 `G = exp(Σ_f w_f log(ρ_f/ρ0_f))`，`w_f=A_f/ΣA_f`，`ρ_f=N√(|aUV_f|/A_f)`。ρ0 来自该运行的 OptCuts＋统一排布初始状态。每面密度不得低于 `ρ0×(1−1e-5)`；相对分配 `ρ_f/(Gρ0_f)` 限于 [0.9,1.1]。同时报告最小密度、分位数与面积加权均值。
- 每候选经过同一排布器之后才比较 G；严格增加至少 1e-4 才接受。接缝长度、岛数、共享面积和唯一覆盖率只记录/约束，不充当 G 的替代；小于改善阈值时保持原状态，不因浮点差异抖动。
- 全局共同尺度不变的 `D_shape=0.5√(PQ)−1` 要求 ≤0.025；每面各向异性比不超过初始值的 1.10 倍。镜像成员先统一约定方向再计算；拒绝零面积、局部翻转、成员内自重叠、非授权跨组重叠。
- 首轮结构预算：归一化接缝长度 ≤1.25 L0，表面 chart 数 ≤max(K0+8,ceil(1.5K0))；另报实际唯一排布组数，不能靠复用把表面 chart 数隐去。
- 固定 1024²，组间最短距离 ≥16px、图集边界 ≥8px、烘焙扩边 8px；这些是同轮配置，须另检验 mip/法线，不声称普遍安全。
- 外观候选门禁：每个成员的每张共享面分别计算合成后 linear RGB 三通道绝对误差，均值 ≤0.025、P95≤0.08、最大值≤0.20；候选每面64个固定分层内部样本，终验检查所有共享有效 texel 中心并补充无 texel 面的分层样本。使用对应采样和开发渲染，不使用正式测试相机。投射/纹理缺失的区域不共享；失败记录颜色、几何、投射等具体原因。`[opinion]`

D_shape 与 G 分离，避免 packing 后全局缩放改变原 V1 SD 指标而造成虚假收益。已有求解适配器没有对应耦合接口，不能以分别全局重跑 OptCuts 冒充成对参数化。`[verified: src/reseam/fixed_uv.py“shape_distortion”；src/reseam/solver.py 的 request 字段]`

## 2. 区域对应、成对 UV 与联合搜索

### 连续区域对应

1. 复用顶点—曲面投射；对坐标轴和 PCA 法向生成候选，分别拟合偏移，按双向、面积加权、截尾曲面距离选初始平面。不修改输入几何；预置左右翼掩码仅作诊断，正式候选不使用未确认语义标签。
2. 初筛位置与往返误差 ≤0.005D、法线夹角 ≤45°，D 为原始包围盒对角线；要求映射到对侧，排除中线 0.02D 带。增加面内部与边中点采样，不仅检查顶点。
3. 在原始面邻接上组连片，目标支持面也须连通；至少 8 面/侧且至少一侧占原表面积 0.5%。相邻映射边长度比须在 [0.5,2]；剔除翻折、跨部件跳跃和多对一塌缩后重新分组。
4. 只以原始边界或原始网格边形成区域切缝。非圆盘区域先用已有边界桥接切法拆成圆盘；失败记 REGION_TOPOLOGY_FAILED，不强行修改几何。每候选保存缩减前后的面集，避免悄悄把大区域换成少量容易成功的点。`[opinion]`

### 成对参数化与部分共享

- 两侧保留各自三角化，分别作凸圆周初始化；测试8个循环相位及镜像奇偶性，仅选择合法且残差较小的初值。不同边界采样产生不同的分段线性域，不能称为同一个圆盘；初始化之后边界参与求解，不固定在圆周，也不直接平均旧 UV。
- 新增 Python 成对求解器。原始几何统一除以全模型 √总面积；目标 `E=Σ_f w_f SD(J_f)+λ C/a0`，其中 `SD(J)=¼(||J||²_F+||J⁻¹||²_F)−1`、w_f按配对区域三维面积归一化，C为双向重心对应的平方UV残差加权均值（采样权重按代表三维面积归一化），a0为两侧初始UV面积之和并固定。λ=1/10/100为无量纲三档；不把尺度当作SD的自由度钉死。只固定整体平移和旋转：一个锚点在原点、第二个锚点在正水平轴且横坐标可动。采用回溯梯度步，最多200次迭代并服从deadline，梯度先用有限差分校验。
- 每成员预先记录方向奇偶性H（普通I、镜像diag(-1,1)），回溯要求 det(HJ)>0，并全量检查成员内单射；不允许局部杂乱翻转。求解后用一个共同标量将该组两侧UV面积之和恢复至a0，禁止逐成员恢复尺度；然后放回全模型重新检查D_shape与密度门禁。该恢复是明确的工程步骤，不宣称仍是E的最优解。
- 共享部分是两个域的实际交集，单侧覆盖的边缘仍由该成员独立使用；packing使用两个域的并集。既不要求两个离散边界完全重合，也不因此丢弃表面。排布尺度下对应耦合残差P95≤1px仅作为附加门禁，不能替代逐交叠单元验证。
- 对每对跨成员UV三角形的正面积交集，做精确多边形裁剪并检查所有单元顶点：经各自重心坐标回到三维后，镜像对应位置的欧氏差最大≤0.005D；两原始面的反射几何法线夹角≤45°，D为原始包围盒对角线。每单元的三维差是UV上的仿射函数，顶点误差界约束整个凸单元的位置误差；所有交叠单元都须通过，不用全局P95掩盖局部违例。同成员自重叠和跨组重叠始终禁止。失败单元关联面从共享区域移出，重建切缝/参数化后重验，不能仅在日志里取消许可而保留交叠。
- 每组先生成各成员的投射样本，再按原始表面面积贡献在线性空间融合Base Color，不跨不相容材质绑定共享。法线参考为高模着色法线，先分别用各成员实际导出UV的TBN逆变换编码、加权融合并归一化；随后分别用每成员TBN解码。每张共享面上的角误差均值≤5°、P95≤15°、最大≤30°；候选使用64个分层点，终验检查所有共享texel中心并补足无texel面。无源法线贴图时使用高模几何着色法线，绑定不明或投射失败不算零误差。任何成员失败都撤销该复用组或拆分后重新验收，禁止单侧通过即批准。`[opinion]`

### 接缝—排布反馈

- 独立 V2 搜索入口调用现有区域切缝提案组件，取消“接缝必须变短”的预筛选；不修改 V1 search.accept 的历史口径。
- 按边界接触、细长空隙/凹陷和接近畸变上限的区域生成候选，80% 优先瓶颈、20% 固定种子随机探索。候选覆盖相邻 2–4 个完整表面 chart，并扩展到受影响复用组的全部成员。
- 提案包括区域合并重切、路径替换、生成树重建、复用区域缩减/解除及新增部分共享。复用组边界切缝是复用轨道的必要成本；只有 seam 开关开启时才进行排布反馈驱动的额外重构。
- 支持域按 1 环、3 环、全部受影响组扩大；共同起点和总预算保持一致。组级 packing 以现有 Blender 姿态提案和原形重构为首选，失败保留原布局；无论方法是否产生新几何候选，使用同一个 packing 配置。
- 每个完整候选重新求解、排布、验证并比较 G；记录成本及各阶段失败。最佳状态连同 UV、对应、复用组、纹理引用和版本原子提交；异常/超时完整回退。`[opinion]`

## 3. 重烘焙、代理盲评与结论产物

### 下游和接口

- 下游增加“已验证排布输入”入口，禁止现有 evaluate() 再执行 average_islands_scale/重新 pack 而破坏实验。普通非共享结果仍保留原流水线。
- 保持完整低模几何及法线连续性，成员独立投射到临时纹理，合成共享组；不得删去一侧面再依赖改变后的顶点法线进行烘焙，也不得让重叠面无控制地争写像素。保留投射命中与冲突记录。
- 24 个输出均进行 Base Color、切线法线和 256²/128² mip 对拍。固定现有六个评估相机为本轮测试相机；开发比较另用方位 0/90/180/270、仰角 20° 的相机。既有测试相机是回归视角，不声称从未被观察过。
- 主对照使用烘焙结果，不通过可微优化改变主排名。若预算允许，另列固定预算可微优化的配对辅助结果；未运行不补造。
- 导出 GLB 验证逐角 UV、几何和镜像切线方向；保存模型、纹理、UV、mask、同视角渲染、局部裁剪和机器可读质量记录。`[opinion]`

### 盲评协议

- 每个模型/种子为一包，四个方法都在预先生成的匿名映射中；6 包×3 位评审，共 18 次首轮评审。私有解码表与评审目录隔离，清除方法名、源路径、历史结论等身份泄漏；每包相同图像尺度、相机及裁剪框。
- 编排层使用 `collaboration.spawn_agent` 的 `fork_turns="none"`，每次新建评审上下文；评审只读匿名包和固定 rubric。Python 命令负责 export/import 与聚合，不假装可直接调用当前会话的协作工具。记录实际运行器可获得的模型身份、提示词哈希及原始输出；无法取得的元数据写 unavailable，不编造。
- 四维 1–5 分的统一锚点：1 明显不可用，2 明显缺陷，3 需修整，4 接近可用，5 在提供证据中未见明显问题。UV 编辑性只是图像/结构代理，不预测或伪造修整分钟数。任一维缺少相应证据则该维不评分。
- 评审 JSON 包含匿名样例、四维分数或 null、每维 evidence 图像 ID/区域和理由、四组样例间六对偏好（胜/平/负/无法判断）。导入时核对包哈希、样例全集、分值范围和 evidence ID；格式/证据不合格最多以新上下文重试一次。
- 各维至少两份有效评分才取中位数；同时保存范围与分歧，分差≥2标记 disagreement。无有效证据的比较保持无法判断，不把缺失评分补零。技术不合格样例保持 FAILED_QUALITY，不通过 LLM 评分洗成成功。
- `AGENT_EVALUATED` 只表示完成代理评审。另列代理推荐：技术通过、四维中位数均≥4且至少两位评审未发现重大缺陷；不满足则 NEEDS_WORK，证据不足则 UNSCORED。human_acceptance 保持 NOT_REVIEWED 或实际人工结果，不阻塞技术/实验完成。
- 代理仅评分阶段产物和冻结后的正式包，不对每次候选调用 LLM。开发评分与正式评分目录、提示词版本分开，正式评价反馈只可影响下一 round。`[opinion]`

### 结论记录

每轮输出 `hypotheses.md`、锁定 protocol、逐候选 JSONL、24 行完整 matrix、匿名包 manifest、原始 reviews、review_summary 和 `conclusions.md`。每条结论标记“已实现/已验证/代理偏好/待验证假设”，附模型、种子、比较对象、指标/评分差值和证据路径；必须写负结果、失败分母、评审分歧和下一步，不以最好一次代替总体。`[opinion]`

## 4. A/B、预算、测试和实施顺序

### 最低正式矩阵

轨道锁定为 `packing_only`、`seam_pack`、`reuse_pack`、`joint`；模型 energy_blade、dragon；种子17、29、43，共24行。每行从固定低模重新运行相同配置的原版 OptCuts 初始化，初始化失败原样记录；随后使用相同 packer、门禁、搜索总时间和下游配置。无功能开关的轨道可在剩余时间做同配置的多起点 packing，不能跨运行复用最好状态。`[opinion]`

同模型/种子的四轨道记录并核对初始状态哈希；若不同则标 INIT_MISMATCH，保留原始运行但不作共享初值的成对收益结论，修复后另建轮次。不能悄悄使用不同初始密度来计算各自的G并直接宣称机制收益。`[opinion]`

主对比为 joint 对 seam_pack、reuse_pack、packing_only；同时给完整2×2消融的每项原始结果。不能把输入相同的确定性重复或同模型的三个种子当成更多独立资产。对照采用相同时间上限而非声称实际耗时相同；分别报告实际搜索/初始化/验证/导出成本。`[opinion]`

### 新预算账户 v2_joint：28800 秒

- 环境与构造/真实冒烟：3600秒。
- 几何与联合搜索：10800秒，每个正式运行300秒总上限（包含初始化/验证/导出），最多120个完整候选，终验预留15秒；单候选最多30秒但不能越过运行 deadline。
- 重烘焙和下游：7200秒，每行最多270秒，失败保留；其他时间用于统一参考图生成。
- 代理评审：3600秒，每个模型/种子包并发3位评审；每次调用180秒上限，失败最多重试一次且服从阶段总预算。
- 汇总与证据审计：3600秒，不用于看到正式结果后继续调参。`[opinion]`

预算按各阶段实际占用的墙钟记账；并行评审不重复累计重叠墙钟，另存每位评审耗时。阶段封顶，不借用旧账户。超时后保留最好已验证输出；超时产物可诊断展示但不进入“同预算成功”排名。未运行项明确 NOT_RUN_BUDGET，不能勾完整实验完成。编程、文档设计和人工评审不扣自动实验预算。`[opinion]`

### 实施与验证顺序

1. **接口与验证器**：添加组/对应状态、逐区域门禁、共同密度指标、事务档案；先通过不同三角化和近似形状的构造网格，验证源几何不变、重心对应、成员方向、自交与非法组内/组间交叠拒绝。
2. **龙翼成对 UV**：检查解析梯度、边界不同采样、局部退化、对应多对一、非圆盘修复和单边缺失；输出开发相机对拍。只扩大误差阈值或跳过配准检查不算完成该阶段。
3. **组级排布与重烘焙**：校验共享变换、密度底线、16/8px间距、双成员写入冲突、镜像TBN及GLB逐角往返；失败自动恢复完整无共享初始状态。
4. **联合搜索与四轨道**：复用支持域扩展，验证接缝成本上升但最终G改善的候选不会被旧预筛选拒绝；测试随机种子复现、超时档案、输出不覆盖和所有失败落表。能量刀同步回归。

# 匿名 UV 编辑任务与验收规则 v1

这是后续人工评审的统一任务，不代表已完成人工验收。此前两样例的 3／4 分只属于初步视觉偏好。

## 编辑任务

逐个打开匿名样例的 editable.blend。只修改切缝和 UV：修整你认为妨碍纹理绘制的小碎岛、细长分支和曲折边界，保护已确认的重要区域，并改善你认为明显不合理的局部拉伸。允许保留必要的多个岛，不以岛数最少作为通过条件。

首次打开后，在 Text Editor 选择内嵌的 `reseam_annotation_addon.py` 并运行；3D 视图侧栏的 ReSeam 面板提供标注与导出功能。

不得改变顶点位置、面、拓扑或对象变换，不替换高模、低模或材质内容。没有已确认的语义标注时，不假定自动建议是正确部件边界；可另行标注并说明。

## 计时与操作记录

- 文件和参考图加载完成后开始计时，每样例最多 15 分钟；到时停止，不将超时样例勾为完成。
- 人工编辑、试展 UV、观察和决策计入修整时间；后续自动验证与重烘焙耗时单独记录。
- 使用场景中的 ReSeam 面板导出当前 UV JSON，记录实际删除／新增接缝、合并／拆分岛及松弛操作。没有完成编辑时仍保存原因，不以“未完成”代替缺失记录。
- 偏好评分采用整数 1–5：1 明显妨碍编辑；2 需要较多修整；3 可作为起点但仍需修整；4 接近可用、少量修整；5 在本任务下无明显修整需求。评分与技术门禁、交付结论分别记录。

## 技术检查与重新烘焙

在项目中执行：

```powershell
uv run python scripts/validate_artist_edit.py <edited_uv.json> --model <energy_blade或dragon> --output artifacts/reviews/<新的编号> --bake
```

如有人工确认的硬约束，增加 `--annotations <confirmed.json>`。检查固定几何与面身份、UV 面覆盖、流形平面岛、方向一致性、岛内无自重叠、平均 SD≤0.025，以及必须切／禁止切要求。

UV 采用项目统一的尺度与整岛方向约定，重烘焙前统一打包；打包位置不属于本轮编辑评分对象。图集 1024²、岛间至少 16 像素、扩边 8 像素。变更 UV 后必须重新烘焙 Base Color 和切线空间法线，不能把旧贴图仍然可见当作新 UV 正确。

## 交付判据

同时满足：技术检查通过、限时内完成任务、保留全部已确认硬约束，并经本人检查重烘焙后的指定视角、接缝局部及 mip，没有你认为不可接受的接缝、纹样破坏或局部拉伸。保留编辑 UV JSON、确认约束、修改记录、计时、评分和重烘焙结果。

网页勾选只表示评审者的声明，不自动证明技术检查或视觉交付通过。技术验证脚本也不会代替人的审美判断；未完成人工环节时保持待验收。

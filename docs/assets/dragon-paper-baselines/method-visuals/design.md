# 机制对照

以真实几何与UV为主体，让图像承担比较。统一的模型镜头、UV画幅和数字尺度建立共同参照；每张卡片用一个短流程解释方法的主要动作。机制示意与实际资产在空间上分开，读者能辨认概念图和实测图。`[opinion]`

浅灰蓝背景保留呼吸空间，深蓝标题稳定阅读顺序。紫色指向神经映射，蓝色指向几何工具，橙色指向Agent规划，青色指向共享；色彩表达方法类别，避免把类别误读为结果排名。细线、圆角和留白保持一致。`[opinion]`

视觉精度来自逐项对齐：模型与UV保持比例，数字使用相同字级，箭头与节点只表达处理顺序。少量大字给出岛、图块、共享的关键差别，次级文字只说明实验设置。细节检查集中在真实资产的清晰度、文字边界和标注间距。`[opinion]`

质量状态使用独立的小标签：通过、拒绝和未评估分别表达，不用同色模型或少岛数暗示通过。失败路径继续展示其实际棋盘格与原生UV，完成路径展示真实BaseColor模型。总览便于横向观察，独立卡片便于放大阅读。`[opinion]`

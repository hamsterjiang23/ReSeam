# 分层索引

以对齐和分支关系承载信息。两张横向索引图用于查找，纵向导图用于理解联系；读者先识别方法，再辨认来源、执行与结果。版面精度来自文字基线、列宽和节点间距的细致校准。`[opinion]`

白底与深蓝正文构成稳定的阅读层级。蓝、绿、紫、橙、红分别标识方法来源、指标、结构、实施和结论；颜色表达章节关系，避免作为算法质量排名。`[opinion]`

字体以微软雅黑为中文主体，英文论文标题使用衬线斜体。标题、核心判断、来源注释保持三个字号层级；逐块核验宽度与高度，长句在明确边界内换行，保留必要留白。`[opinion]`

导图通过共同主干与五个分支组织复杂内容。Research Track与Asset Track并列，来源事实与项目判断分开；数字直接读取冻结结果，失败与拒绝结论保持可见。精细制作体现在对齐、可读性与证据的完整对应。`[opinion]`

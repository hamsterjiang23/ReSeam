# 论文指标补算

## Deviations

- 本轮只读已有快照，另存评估侧表，不改变冻结算法、输入或原始measurements.json。
- A.6给出AO比较公式与1000×8采样，但未明确随机序列、距离上限和偏移。使用固定seed17与明确参数；同时记录显式切缝及含原边界两种范围，不混作作者代码复现。

## Discovered edge cases

- 无显式切缝的原生输出无法定义“显式切缝AO”；保留不适用及原边界范围的独立AO，不能用0或0.5补值。
- 失败UV可能重叠、退化或没有边界；形状指标按论文公式计算并报告跳过数量，不能据此升级质量状态。
- baseline/为仓库工具而非已安装Python包；pytest显式加入仓库根路径，以保持`uv run pytest`可以直接收集新增评估测试。
- A.6的Jaggedness公式为原始UV单位的二阶差分，不能从表1的数值反推倍率；保留原值、步长和样本数，明确其尺度依赖。
- 射线最大距离2倍包围盒对角线覆盖有限模型；A.3的0.3倍局部AO是另一属性，不替代A.6全表面比较。

执行摘要：公开公式的5项缺失指标已补算，另保留AO范围、正交度与样本数诊断。
实现选择：AO种子/偏移/射线范围与Jaggedness聚合明确记录；回访时先核对作者是否发布评估源码。
边界情形：无显式切缝、退化UV、非圆盘拓扑与原始跨几何参考分别保留。
执行证据：九条路径完整1000×8采样共约110.14秒，输入与历史质量状态未改。
